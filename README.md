# AirServe (极简、优雅的本地原型交付与静态服务工具)

AirServe 是一个基于 **`pywebview`** 和 **`miniserve`** 的跨平台 (Windows/macOS) 本地静态文件服务器图形界面工具。采用现代 Web 前端技术打造苹果级（Apple / macOS）毛玻璃精美界面，专为产品经理、前端开发者与售前人员设计，支持一键启动本地 Web 服务以及**一键封包导出单文件独立原型演示 EXE**。

---

## ✨ 核心特性

- **🍎 苹果原生质感 UI**: 基于现代 CSS 毛玻璃 (Glassmorphism)、SF 字体排版与微交互动效构建，精致美观。
- **📦 一键封包单文件独立 EXE**: 选定原型目录后，一键生成完全独立的单文件 `.exe`。客户无需安装任何环境，双击即可离线运行并自动打开浏览器展示。
- **🎮 智能二合一主控按钮 (Scheme A)**: 宽幅灵动主控大按钮 + 自动滑出的快捷重启按键，提供极致的按压反馈与操作效率。
- **🔌 端口自定义与智能冲突检测**: 自由指定服务端口；端口被占用时支持自动递增切换至可用端口，彻底告别端口冲突困扰。
- **🕒 历史路径记忆与管理**: 自动持久化保存最近使用过的静态资源目录，支持下拉列表一键切换、单条精准删除 (`×`) 与一键清空。
- **🛡️ 入口文件校验与智能定位**: 自动校验目录下是否存在 `index.html`，智能识别并自动修正至 `dist/` 或 `build/` 子目录。
- **🌐 Safari 风格地址胶囊**: 启动后展示带呼吸光晕的实时状态、一键复制访问链接与快速直达浏览器。
- **🧹 全生命周期进程销毁**: 绑定窗口关闭事件与退出钩子，退出时递归强制销毁子进程树，杜绝后台残留。
- **⚡ 跨平台 & SPA 原生支持**: 自动适配 Windows 与 macOS，默认开启 `--spa` 模式并内置防缓存请求头，完美支持 Vue / React / Vite / Next 等单页应用。

---

## 🚀 如何使用

1. 安装相关依赖 (`pip install -r requirements.txt`)。
2. 确保 `bin/` 目录下有对应平台的 `miniserve` 可执行文件 (`miniserve-win.exe` 或 `miniserve-mac-x64`)。
3. 运行主程序 `python main.py`。
4. 在图形界面中选择或输入静态文件目录，调整端口配置后点击 **“▶ 启动服务”**。
5. 如需将当前原型打包发给客户离线体验，直接点击 **“📦 导出独立 EXE”** 即可秒级生成独立演示程序。

## 📦 客户端打包

项目附带了跨平台的自动化打包脚本，可分别在 Windows 与 macOS 系统上一键构建独立应用包：

### 🪟 Windows 构建：
```cmd
build_win.bat
```
打包生成的可执行程序位于 `dist/AirServe.exe`。

### 🍎 macOS 构建：
```bash
chmod +x build_mac.sh && ./build_mac.sh
```
打包生成原生独立 App 位于 `dist/AirServe.app`。
